# Staged manifest rows — NOT generated, NOT part of the series

This file is **hand-written**, and it is the only file in this directory that is. Everything else
here — `MANIFEST.md` and every `NNNN-*.patch` — is generated by
`python tools/arifi-sync/arifi_sync.py series regen` and must never be edited by hand.

## Why this file exists

`series regen` is the only lawful way into `patches/series/`, and it currently **stops on ten
pre-existing merge commits** in the fork's history. That block is not caused by any of the work
below and cannot be cleared from inside it: unblocking it means an authorised linearization of the
default branch.

The tempting shortcut is to append the rows straight into `MANIFEST.md`. That produces an artifact
that **looks** green and dies at the next `git am`, because the manifest is a function of the patch
files beside it and hand-editing one without the other breaks exactly the correspondence
`series check` exists to verify. So the rows are staged here instead, in the format the generator
emits, and `MANIFEST.md` is left alone.

**This file is superseded the moment `series regen` runs.** The regeneration writes the real rows
into `MANIFEST.md` from git, and this file should be deleted in the same change. It is a note for a
blocked step, not a second source of truth — where the two ever disagree, git is right and this file
is stale. The generator does not read it, and cannot: patch enumeration matches `^\d{4}-.*\.patch$`,
so nothing here is visible to `series check` or to `git am patches/series/*.patch`.

## Verification that was possible without regenerating

For the one commit below that is on the default branch, the question the series answers — *does this
replay cleanly?* — was answered directly at the right scope rather than skipped:

```
git format-patch -1 5b1b416cb
git apply --check <the patch> # against the replay result f78ac1ee1 -> rc=0
```

Independently re-verified with a negative control. The series counts before and after that landing:
**513 → 517 commits, 10 → 10 merge commits (it adds none), provenance FAIL 57 → 57 (every new commit
is trailered), 415 → 415 patches on disk** — the last pair being precisely the blocked step.
