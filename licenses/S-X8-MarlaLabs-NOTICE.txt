NOTICE
======

This repository contains the **S-X8 v4.3 quantization format** (original work of the author) and a
**quantized variant of the model Qwen3.8-27B**:

  Qwen3.8-27B
  Copyright (C) 2026 Qwen Team, Alibaba Group
  https://huggingface.co/Qwen/Qwen3.8-27B
  Licensed under the Apache License, Version 2.0

The S-X8 format, kernels, scripts and paper are **original work, not a Qwen work**; they use
Qwen3.8-27B only as the base model. Modifications made to the base model:
  - The weights of the transformer (27.78B parameters) were quantized to the
    S-X8 v4.3 format (7.50 bits per weight) developed in this repository.
  - No other modifications were made to the model.

The S-X8 format is validated on **Qwen3.5-4B-SX8** (https://huggingface.co/marlalabsAI/Qwen3.5-4B-SX8);
this 27B model uses the same pipeline and is validated functionally (local test).
